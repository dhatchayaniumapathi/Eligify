# Rule-Based Eligibility Engine — Eligify AI Engine

> **Module Location:** `ai_engine/rules/`  
> **Status:** Active / Milestone 3 Completed  

The **Rule-Based Eligibility Engine** is a deterministic, modular Python engine designed to evaluate citizen profiles (`UserProfile`) against government welfare scheme specifications (`Scheme`). It performs granular condition checks across 8 eligibility criteria, calculates a match confidence score, and returns an explanatory verdict (`EligibilityResult`).

---

## 🏗️ Module Architecture

```text
ai_engine/rules/
├── models.py              # Pydantic schemas (UserProfile, Scheme, EligibilityResult)
├── condition_matchers.py  # Granular matching functions (Age, Gender, Income, etc.)
├── evaluator.py           # Core engine entrypoint: evaluate_eligibility()
├── exceptions.py         # Custom exception hierarchy (InvalidProfileError, etc.)
└── README.md              # Module documentation & developer guide
```

## 📊 Data Models (`models.py`)

### 1. `UserProfile`
Represents the user's demographic, financial, and occupational attributes.

| Field | Type | Description |
| :--- | :--- | :--- |
| `age` | `int` | User age in years (0 to 120) |
| `gender` | `str` | Gender (`Male`, `Female`, `Transgender`, `All`) |
| `category` | `str` | Social Category (`General`, `SC`, `ST`, `OBC`, `Minority`, `All`) |
| `annual_income` | `float` | Annual family income in INR (>= 0.0) |
| `state` | `str` | Residence State (`Tamil Nadu`, `Karnataka`, `All`, etc.) |
| `occupation` | `str` | Occupation (`Farmer`, `Student`, `Unemployed`, `Self-Employed`, `Senior Citizen`, `All`) |
| `disability` | `bool` | Benchmark disability status (True if >= 40% disability) |
| `education` | `str` | Qualification (`Below 10th`, `10th Pass`, `12th Pass`, `Graduate`, `Post Graduate`, `All`) |

### 2. `Scheme`
Represents scheme qualification requirements matching the dataset schema.

| Field | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `scheme_id` | `str` | **Required** | Unique scheme code (e.g., `SCH001`) |
| `scheme_name` | `str` | **Required** | Scheme title |
| `ministry` | `str` | **Required** | Administering Ministry |
| `state` | `str` | `"All"` | Target State jurisdiction |
| `min_age` | `int` | `0` | Minimum age required |
| `max_age` | `int` | `99` | Maximum age allowed |
| `gender` | `str` | `"All"` | Target gender qualification |
| `category` | `str` | `"All"` | Target social category |
| `max_income` | `float` | `0.0` | Maximum income ceiling (0.0 = no cap) |
| `occupation` | `str` | `"All"` | Target occupation |
| `disability_required` | `bool` | `False` | Mandatory disability requirement |
| `education` | `str` | `"All"` | Minimum education standard |
| `benefits` | `str` | `""` | Scheme benefit summary |
| `required_documents` | `List[str]` | `[]` | Document checklist |
| `application_link` | `str` | `""` | Official application portal URL |

### 3. `EligibilityResult`
Output object generated by `evaluate_eligibility()`.

| Field | Type | Description |
| :--- | :--- | :--- |
| `scheme_id` | `str` | Scheme identifier |
| `scheme_name` | `str` | Scheme title evaluated |
| `eligible` | `bool` | `True` if user passes all criteria, `False` otherwise |
| `confidence` | `float` | Proportion of matched criteria (0.0 to 1.0) |
| `matched_conditions` | `List[str]` | Detailed list of rules passed |
| `failed_conditions` | `List[str]` | Detailed list of rules failed |
| `explanation` | `str` | Human-readable verdict summary |

---

## ⚙️ Condition Matchers (`condition_matchers.py`)

The engine executes 8 independent rule matchers:

1. **`match_age`**: Validates `min_age <= user_age <= max_age`.
2. **`match_gender`**: Checks gender match or `All` wildcard.
3. **`match_category`**: Checks category match or `All` wildcard.
4. **`match_income`**: Checks if `user_income <= max_income` (ignored if `max_income == 0`).
5. **`match_state`**: Checks state match or `Pan-India`/`Central` wildcard.
6. **`match_occupation`**: Checks occupation match or `Senior Citizen` age rule (`age >= 60`).
7. **`match_disability`**: Enforces mandatory disability prerequisite when `disability_required=True`.
8. **`match_education`**: Enforces hierarchical education level comparison (`Graduate >= 12th Pass >= 10th Pass`).

## 🚀 Usage Examples

### 1. Basic Eligibility Evaluation

```python
from ai_engine.rules.models import UserProfile, Scheme
from ai_engine.rules.evaluator import evaluate_eligibility

# 1. Define User Profile
user = UserProfile(
    age=25,
    gender="Female",
    category="General",
    annual_income=150000.0,
    state="Madhya Pradesh",
    occupation="Unemployed",
    disability=False,
    education="12th Pass"
)

# 2. Define Scheme
scheme = Scheme(
    scheme_id="SCH012",
    scheme_name="Chief Minister Ladli Behna Yojana",
    ministry="Department of Women and Child Development",
    state="Madhya Pradesh",
    min_age=21,
    max_age=60,
    gender="Female",
    category="All",
    max_income=250000.0,
    occupation="All",
    disability_required=False,
    education="All",
    benefits="Monthly assistance of Rs. 1250",
    required_documents=["Aadhaar Card", "Samagra ID"]
)

# 3. Evaluate
result = evaluate_eligibility(user, scheme)

print(f"Eligible: {result.eligible}")
print(f"Confidence Score: {result.confidence}")
print(f"Verdict: {result.explanation}")
```

### 2. Evaluating Dataset Schemes

```python
from ai_engine.dataset.loader import load_schemes_csv
from ai_engine.rules.models import UserProfile, Scheme
from ai_engine.rules.evaluator import evaluate_eligibility

# Load schemes from dataset CSV
dataset_schemes = load_schemes_csv()

user = UserProfile(
    age=65,
    gender="Male",
    category="General",
    annual_income=50000.0,
    state="All",
    occupation="Senior Citizen",
    disability=False,
    education="10th Pass"
)

eligible_schemes = []

for raw_scheme in dataset_schemes:
    scheme_obj = Scheme(**raw_scheme)
    res = evaluate_eligibility(user, scheme_obj)
    if res.eligible:
        eligible_schemes.append(res)

print(f"User is eligible for {len(eligible_schemes)} schemes!")
for match in eligible_schemes:
    print(f" - {match.scheme_name} (Confidence: {match.confidence})")
```
